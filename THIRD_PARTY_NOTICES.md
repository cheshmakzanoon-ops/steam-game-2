## Other dependencies

There are no project runtime plugins, external fonts, textures, audio packs, service SDKs or marketplace assets in this bootstrap. The status label uses the engine's built-in presentation resources. Python and Git are external verification/development tools, not runtime dependencies.

The Phase 002 licensing policy remains controlling. Its example CSV row is a template, not an approved font. Each future external source must have author, exact version, source, license, modification/redistribution conditions, attribution and evidence before import. Source and generated-asset manifests start empty; do not claim placeholders as licensed final assets.
