## Normal / boundary / failure-recovery evidence

**Normal:** new world/UI/content names use the canonical lexicon, stable IDs and capitalization rules.

**Boundary:** poetic boss/event naming is allowed when it remains readable and original; public title use remains replaceable until clearance.

**Failure:** a confusingly similar mark, competitor-derived phrase, inaccessible terminology or display name embedded in save identity blocks approval.

**Recovery:** freeze title-dependent spending, retain stable internal IDs, choose/search a replacement, update presentation/store metadata and preserve the decision history.
