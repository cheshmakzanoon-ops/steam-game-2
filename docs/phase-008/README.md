# Phase 008 — Production roadmap and dependency graph

This package turns all 120 mandatory phases into a capacity-aware roadmap without inventing fixed dates.

## Artifacts

- `PHASE_ESTIMATES.csv` — all 120 phase estimates, confidence, predecessor, window, milestone/review flags, and acceptance weights.
- `ROADMAP_MODEL.json` — staffing, capacity, contingency, milestone, review, and burndown constants.
- `DEPENDENCY_GRAPH.md` — hard critical path and parallel-safe preparation lanes.
- `MILESTONE_CALENDAR.md` — relative prototype, vertical-slice, demo, alpha, beta, RC, launch, and post-launch windows.
- `CONTINGENCY_AND_PIVOT_PLAN.md` — protected 75-day reserve and review/recovery rules.
- `WEEKLY_DASHBOARD_TEMPLATE.md` — accepted-work burndown and operating review.
- `verify_roadmap.py` — offline model verification.

No future phase is complete merely because it appears here.
