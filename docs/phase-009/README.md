# Phase 009 — Risk register and kill criteria

Artifacts:

- `LIVING_RISK_REGISTER.csv` — 26 scored commercial/design/technical/art/schedule/operations risks.
- `RISK_SCORING_AND_POLICY.md` — probability/impact/detectability method and status policy.
- `KILL_CRITERIA.md` — prototype, readability, fair-loss, performance, throughput, budget, demo, beta/RC red lines.
- `MITIGATION_SCHEDULE.md` — mitigation owners and evidence windows.
- `REVIEW_CADENCE.md` — phase/weekly/monthly/formal/incident review cadence.
- `RISK_MODEL.json` — machine-readable threshold constants.
- `verify_risks.py` — offline consistency checker.

Thresholds are precommitted future evidence gates. They are not claims that an unbuilt prototype or future launch build already passes.
