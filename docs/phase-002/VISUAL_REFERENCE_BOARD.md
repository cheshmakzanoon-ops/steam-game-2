# Phase 002 — Visual Reference Board

**Artifact:** visual_reference_board.svg  
**Status:** APPROVED EXPLORATORY GRAMMAR — NOT FINAL ART  
**Date:** 2026-09-22

The SVG committed beside this file is an **original abstract reference board** constructed for Signalhold. It contains no competitor screenshots and no copied contemporary artwork.

Its purpose is to establish material and mark-making directions broad enough to be original while concrete enough to constrain later Blender and UI work.

## Reference families

### 1. Rag paper / parchment substrate

Use:
- warm off-white base;
- subtle fiber direction;
- worn/deckled edge suggestion;
- restrained staining.

Avoid:
- noisy parchment filters that reduce UI legibility;
- direct scans without provenance.

### 2. Woodcut / relief-print mark making

Use:
- bold silhouette;
- carved hatching;
- variable imperfect edge;
- high-contrast shape grouping.

Avoid:
- copying a single historical print composition;
- reproducing recognizable contemporary game assets.

### 3. Screen-print registration

Use:
- limited functional inks;
- slight intentional offset on decorative print layers;
- solid graphic shapes;
- occasional imperfect ink coverage.

Avoid:
- misregistration on critical text/icons;
- effects that obscure board state.

### 4. Paper-cut relief

Use:
- visibly layered card thickness;
- cast shadow as depth cue;
- beveled/chamfered paper edges;
- simple modular parts with one signature silhouette per structure.

Avoid:
- generic low-poly fantasy look;
- excessive 3D perspective.

### 5. Charter / map notation

Use:
- line networks;
- seals;
- ledgers;
- map tabs;
- route marks;
- stamped labels;
- knot/relay motifs.

Avoid:
- reproducing a specific historical map or modern game HUD.

### 6. Material accents

Use selectively:
- sealing wax;
- twine/thread;
- brass/tarnished metal pin;
- charcoal ink;
- embossed paper.

These accents are secondary to board readability.

## Functional color assignment

The board preview encodes the bible's functional palette:

- substrate — warm parchment;
- ink — charcoal;
- player Command — desaturated gold / warm white;
- Supply — muted green;
- Material — rust orange;
- Insight — blue-violet;
- immediate danger — vermilion;
- Hush — cold near-black with pale cyan contamination.

Color never acts alone: shape, line, pattern, icon or motion must also communicate state.

## Production boundary

This board is exploratory reference composition only. It does not authorize final building silhouettes, final UI layout, final logo, final font choice or title treatment.

Any later visual artifact must still pass:
- source/provenance review;
- silhouette/readability review;
- originality review;
- licensing review;
- engine-scale validation.
