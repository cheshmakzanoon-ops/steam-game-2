# Phase 002 — IP Safety Checklist

**Status:** MANDATORY GATE  
**Date:** 2026-09-22

This checklist is production hygiene, not legal advice. If a material trademark, copyright, patent, publicity-right or license question remains ambiguous, stop public use of the affected material and obtain qualified advice.

---

## A. Before creating or importing any asset

- [ ] Asset/content ID exists.
- [ ] Strategic or presentation purpose is documented.
- [ ] Source is original, commissioned, licensed, public-domain/CC0 with provenance, or otherwise explicitly approved.
- [ ] Author/creator identity is recorded.
- [ ] Source URL or purchase/commission record is recorded where applicable.
- [ ] License name/version is recorded.
- [ ] Commercial use is permitted.
- [ ] Modification is permitted if production requires modification.
- [ ] Attribution requirements are known and budgeted in credits.
- [ ] Redistribution restrictions are compatible with packaging the game.
- [ ] License evidence is retained outside the public repo if it contains personal/payment information.
- [ ] The licensing register row is complete before the asset becomes a production dependency.

## B. Copyright/originality

- [ ] No tracing, paint-over or close redraw of a competitor screenshot.
- [ ] No copied UI layout or screen composition.
- [ ] No copied character/building silhouette.
- [ ] No copied icon.
- [ ] No copied texture, audio sample, font or shader without license.
- [ ] No copied lore paragraph, tooltip, event, achievement or marketing line.
- [ ] No "temporary" copyrighted placeholder is allowed into a shippable asset directory.
- [ ] Reference images are stored/linked as references, not silently repackaged as project assets.
- [ ] An AI-assisted asset, if used, does not deliberately imitate a living artist or protected commercial style/character/logo and has its generation/source record retained.
- [ ] Every Blender-generated production asset can be traced to project-authored geometry/materials or licensed source components.

## C. Names and trademarks

- [ ] Working name is clearly marked provisional until clearance.
- [ ] Exact and fuzzy searches are performed in target territories.
- [ ] Similar meanings, spacing, hyphenation, pluralization and phonetic variants are searched.
- [ ] Relevant goods/services are considered, not merely exact-word matches.
- [ ] Steam and major game storefronts are searched.
- [ ] General web, developer/publisher names, company registries, domains and social handles are searched.
- [ ] Results are dated and stored in the naming log.
- [ ] A red/amber result has written owner disposition before public use.
- [ ] Final public title is reviewed before logo lock/store publication.
- [ ] The word "cleared" is never used merely because a quick search returned no result.

## D. Third-party code/plugins/tools

- [ ] Dependency is necessary.
- [ ] Exact version is pinned.
- [ ] License is recorded.
- [ ] License obligations are compatible with shipping.
- [ ] Required notices/source offers are understood.
- [ ] Removal/replacement path is documented.
- [ ] Offline behavior remains acceptable.
- [ ] No dependency is added only because it is fashionable or convenient.

## E. Fonts

- [ ] Font license covers commercial desktop/game embedding.
- [ ] Redistribution/embedding restrictions are understood.
- [ ] Variable/static font files used are recorded.
- [ ] Attribution/OFL notice is included if required.
- [ ] No font file is copied from another game/application install.

## F. Audio

- [ ] Every recording/sample has a provenance row.
- [ ] Sample-library EULA permits use in an interactive commercial game.
- [ ] No standalone sample is redistributed in a form prohibited by the EULA.
- [ ] Music commission agreement states deliverables and rights.
- [ ] Voice performance is out of launch scope unless scope is explicitly changed.

## G. Marketing/store

- [ ] All screenshots show the actual project.
- [ ] No competitor logo or capsule is used.
- [ ] No "spiritual successor", "official", "compatible with", or affiliation claim is made without rights.
- [ ] No copied store copy, tag line, trailer structure, press quote or comparison graphic.
- [ ] Features promised in copy exist in the build or are clearly labeled.
- [ ] Title clearance is complete before Steam-page publication.
- [ ] Key art source files and licenses are registered.

## H. Milestone closure

- [ ] Originality review gate completed.
- [ ] New names reviewed.
- [ ] New asset licenses reviewed.
- [ ] New UI/layout reviewed.
- [ ] New progression reviewed.
- [ ] New marketing language reviewed.
- [ ] Licensing register has no unresolved production dependencies.
- [ ] Any RED IP issue blocks closure.
