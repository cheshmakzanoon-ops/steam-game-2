# Working Title Change — 2026-09-22

## Decision

**Old working title:** Signalhold: The Last Relay  
**New working title:** Charterwake: The Last Relay

**Status of new title:** PROVISIONAL / AMBER — not formal trademark clearance.

## Reason

Phase 002 identified an identical UK **SIGNALHOLD** application in software-related classes. Rather than carry that avoidable naming risk forward, the project owner directed the repository to use a different title.

## Why Charterwake

- **Charter** connects to the charter board, authority, seals, ledgers and map language already built into the design.
- **Wake** suggests the trace left by a signal, the aftermath of the Hush, and a kingdom being brought back into action.
- The name does not depend on a competitor's signature mechanic.

A preliminary public-web collision screen on 2026-09-22 did not surface an obvious exact game/software use of **Charterwake** in the queries performed. That is not legal clearance.

## Repository consequences

The active title changes across the README, Phase 001 product/scope/risk documents, Phase 002 originality controls, visual-reference-board labels, naming plan and milestone gate.

Historical references to **Signalhold** remain only where necessary to document the rename reason and the UK application discovered during Phase 002.

## Architecture consequence

None. The project has no gameplay code yet, and the title must never become a save/content identifier.

## Public-use rule

Do not describe **Charterwake** as trademark-cleared until the full Phase 002 naming-validation procedure has been completed and accepted.
