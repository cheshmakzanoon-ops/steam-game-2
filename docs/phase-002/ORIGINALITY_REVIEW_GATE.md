# Phase 002 — Milestone Originality Review Gate

**Status:** REQUIRED FOR ALL LATER PHASE CLOSURES  
**Date:** 2026-09-22

A phase that adds or changes player-facing mechanics, names, UI, progression, art, audio, narrative or marketing cannot close until this gate is reviewed.

---

## 1. Mechanic delta

For each new/changed major mechanic:

- [ ] Closest reference pattern identified.
- [ ] Signalhold-specific player problem documented.
- [ ] Structural difference documented.
- [ ] Difference is visible in actual play, not merely renamed terminology.
- [ ] Mechanic strengthens or preserves one of the six product pillars.
- [ ] Mechanic does not silently expand scope.

**Automatic fail:** the mechanic can be accurately described as "the same thing as [reference], with different art."

---

## 2. Command-network identity

- [ ] Network remains a constructed graph of ports/links.
- [ ] Command remains scarce operational authority.
- [ ] Priority/Load/connectivity behavior remains explicit.
- [ ] No movable gaze/activation rectangle.
- [ ] No hidden network heuristics.
- [ ] Network state remains screenshot-legible where relevant.

---

## 3. Layout/UI

- [ ] UI hierarchy was derived from Signalhold's data/state needs.
- [ ] No competitor screen was used as a tracing/layout template.
- [ ] Resource, threat and Command presentation are independently composed.
- [ ] Icons are project-original or properly licensed.
- [ ] Controller/focus path has equivalent information.
- [ ] Color is not the only state cue.

---

## 4. Art

- [ ] Source asset/provenance is registered.
- [ ] Reference sources are broad historical/material references, not one copied contemporary work.
- [ ] Silhouette is distinct from comparables.
- [ ] Palette/material treatment follows project grammar.
- [ ] No competitor screenshot/asset is embedded in source.
- [ ] AI assistance, if any, has recorded provenance and no prohibited imitation prompt.
- [ ] Blender source and export path are reproducible.

---

## 5. Names/narrative

- [ ] New proper nouns searched for accidental copying inside the project's reference set.
- [ ] Major public-facing names receive naming-risk review.
- [ ] No reference-game vocabulary is retained as placeholder.
- [ ] Event/lore copy is original.
- [ ] Working title status is still respected until cleared.

---

## 6. Progression/content

- [ ] Unlock structure is not copied from a reference.
- [ ] New content has a distinct strategic job.
- [ ] Meta-progression is primarily sideways, not universal-stat compensation.
- [ ] Content remains inside Phase 001 ceilings.
- [ ] No quantity increase is being used to solve a weak core interaction.

---

## 7. Licensing

- [ ] All new third-party dependencies have register rows.
- [ ] License proof exists.
- [ ] Commercial use is allowed.
- [ ] Modification/redistribution conditions are satisfied.
- [ ] Required attribution/notice is captured.
- [ ] No UNKNOWN/RED dependency is required for the milestone.

---

## 8. Marketing

- [ ] No competitor logos/screenshots/capsules.
- [ ] No "X but better", "spiritual successor", "clone", false affiliation or copied tagline.
- [ ] Claims describe actual Signalhold features.
- [ ] Title is not presented as cleared until naming gate passes.

---

## 9. Review result

Choose exactly one:

- **PASS** — no blocking originality/IP issue.
- **PASS WITH RECORDED NON-BLOCKING ISSUE** — issue has owner, mitigation and deadline.
- **FAIL** — phase cannot close.

A FAIL cannot be waived by deleting the evidence or weakening the checklist. Correct the work or obtain explicit owner/legal disposition as appropriate.
